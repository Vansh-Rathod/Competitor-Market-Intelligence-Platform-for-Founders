4️⃣ AGENT DESIGN (THIS IS IMPORTANT)

You don’t need 20 agents.
You need 5–7 well-defined agents.

🤖 Agent 1: Idea Understanding Agent

Model: Claude / GPT-4+
Role:

Extract keywords

Identify ICP

Identify market type

This agent sets the direction for everything else.

🤖 Agent 2: Keyword Expansion Agent

Role:

Generate search queries

Expand market terminology

Handle synonyms

Without this → you miss competitors.

🤖 Agent 3: Data Collection Agents (Multiple)

Role:

Search web

Scrape websites

Collect metadata

These agents are non-LLM heavy, mostly logic + light LLM summarization.

🤖 Agent 4: Competitor Classification Agent

Role:

Remove noise

Classify competitors

Deduplicate companies

This avoids garbage insights.

🤖 Agent 5: Market Analysis Agent

Role:

Calculate saturation

Identify trends

Detect risk signals

This is where strategy begins.

🤖 Agent 6: Differentiation & Opportunity Agent

Role:

Compare features

Compare ICPs

Identify whitespace

This agent is why founders pay.

🤖 Agent 7: Report Generation Agent

Role:

Convert insights → readable output

Founder-friendly language

Clear recommendations
